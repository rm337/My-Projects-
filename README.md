# Spit-Out T-Shirt Machine

**Wordplay + Generative Design by Robert Marleton**

The Spit-Out T-Shirt Machine is an interactive creative concept system that turns words, phrases, observations, accidental expressions, and unexpected connections into potential wearable ideas.

Instead of producing generic slogans, the machine pushes language through word collisions, alternate meanings, phonetic similarities, reversals, invented words, humor, and conceptual twists. The original thought comes from the human; the machine helps push it somewhere unexpected.

## What it demonstrates

- Creative direction and concept development
- Wordplay and linguistic systems
- Generative design thinking
- Interactive experience design
- Brand personality and product ideation
